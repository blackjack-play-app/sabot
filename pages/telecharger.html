Installer sur Windows

  1. Ouvre le fichier {{dl:win:file}} que tu viens de télécharger.
  2. Si Windows affiche « Windows a protégé votre ordinateur », clique sur Informations complémentaires, puis sur Exécuter quand même. Ce message apparaît pour les applications récentes qui n'ont pas encore de certificat de signature payant.
  3. Choisis le dossier d'installation, puis lance Sabot depuis le raccourci du bureau ou le menu Démarrer.

F11 passe en plein écran. La qualité graphique se règle seule. Tu peux la changer dans Réglages → Graphismes.

Installer sur macOS

  1. Ouvre {{dl:mac:file}} et glisse Sabot dans le dossier Applications.
  2. La première fois, fais un clic droit sur Sabot → Ouvrir, puis confirme. macOS demande cette confirmation pour les applications qui ne viennent pas de l'App Store.
  3. Si le message « Sabot est endommagé » apparaît, ouvre le Terminal et tape xattr -cr /Applications/Sabot.app, puis relance.

Installer sur Linux

AppImage (toutes distributions)

  1. Rends le fichier exécutable : chmod +x {{dl:linuxAppImage:file}}
  2. Lance-le : ./{{dl:linuxAppImage:file}}

Paquet .deb (Ubuntu, Debian, Mint)

sudo apt install ./{{dl:linuxDeb:file}}

Transférer ses statistiques

Le site et l'application gardent chacun leurs données sur l'appareil. Pour les retrouver ailleurs : Réglages → Données → Exporter sur l'ancien appareil, puis Importer sur le nouveau.

Désinstaller

Windows : Paramètres → Applications → Sabot → Désinstaller. macOS : mets Sabot à la corbeille. Linux : supprime l'AppImage, ou sudo apt remove sabot.
