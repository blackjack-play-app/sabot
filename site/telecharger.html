Installer sur Windows

  1. Ouvre le fichier BlackjackPlay-Setup-1.1.1-x64.exe que tu viens de télécharger.
  2. Si Windows affiche « Windows a protégé votre ordinateur », clique sur Informations complémentaires, puis sur Exécuter quand même. Ce message apparaît pour les applications récentes qui n'ont pas encore de certificat de signature payant.
  3. Choisis le dossier d'installation, puis lance Blackjack Play depuis le raccourci du bureau ou le menu Démarrer.

F11 passe en plein écran. La qualité graphique se règle seule. Tu peux la changer dans Réglages → Graphismes.

Installer sur macOS

  1. Ouvre BlackjackPlay-1.1.1-macOS-universal.dmg et glisse Blackjack Play dans le dossier Applications.
  2. La première fois, fais un clic droit sur Blackjack Play → Ouvrir, puis confirme. macOS demande cette confirmation pour les applications qui ne viennent pas de l'App Store.
  3. Si le message « Blackjack Play est endommagé » apparaît, ouvre le Terminal et tape xattr -cr /Applications/Blackjack Play.app, puis relance.

Installer sur Linux

AppImage (toutes distributions)

  1. Rends le fichier exécutable : chmod +x BlackjackPlay-1.1.1-Linux-x86_64.AppImage
  2. Lance-le : ./BlackjackPlay-1.1.1-Linux-x86_64.AppImage

Paquet .deb (Ubuntu, Debian, Mint)

sudo apt install ./BlackjackPlay-1.1.1-Linux-amd64.deb

Paquet .rpm (Fedora, openSUSE, RHEL)

sudo dnf install ./BlackjackPlay-1.1.1-Linux-x86_64.rpm ou sudo zypper install ./BlackjackPlay-1.1.1-Linux-x86_64.rpm

Raspberry Pi 4 et 5

Prends la version ARM64 (.deb ou AppImage). Choisis la qualité « Basse » dans Réglages → Graphismes pour un jeu fluide.
